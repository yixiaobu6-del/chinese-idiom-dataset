# 中文成语歇后语数据集

写作成语用错了？

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 成语不再"乱用"

- **成语库**：300条成语+释义+故事
- **歇后语**：150条歇后语+用法
- **语音合成**：TTS朗读发音
- **搜索筛选**：按关键词/分类查找

## 怎么用

打开 `web/search.html` → 搜索成语/歇后语 → 查看详情
